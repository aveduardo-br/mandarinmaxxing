**HSK 3 · Aula 30 · Falar das suas notas · parte 1 de 2**

| Hanzi | Pinyin | Significado |
|---|---|---|
| **数学** | shùxué | matemática |
| **难** | nán | difícil |
| **成绩** | chéngjì | nota, resultado (escolar) |
| **历史** | lìshǐ | história (matéria) |
| **容易** | róngyì | fácil |
| **提高** | tígāo | melhorar, elevar (o nível, as notas) |

**Frases úteis**

**我的数学成绩不太好。**  
*Wǒ de shùxué chéngjì bú tài hǎo.*  
Minhas notas de matemática não são muito boas. (troque 数学 por outra matéria)  
数学成绩 = 数学 (matemática) + 成绩 (nota)

**这次考试很难。**  
*Zhè cì kǎoshì hěn nán.*  
A prova desta vez foi muito difícil. (troque 难 por 容易)

**多学习，成绩就会提高。**  
*Duō xuéxí, chéngjì jiù huì tígāo.*  
Estudando mais, as notas vão melhorar.

## T46 · TUTOR
Quase! Você escreveu:

> 以前数学对我很难，历史很容易。后来我学习每天，最后成绩很好。

**每天** (*měitiān*, todos os dias) é uma palavra de tempo e vem antes do verbo: 我每天学习.

**以前数学对我很难，历史很容易。后来我每天学习，最后成绩很好。**  
*Yǐqián shùxué duì wǒ hěn nán, lìshǐ hěn róngyì. Hòulái wǒ měitiān xuéxí, zuìhòu chéngjì hěn hǎo.*  
Antes, a matemática era difícil para mim, mas a história era fácil. Depois estudei todos os dias e, no final, minhas notas foram boas.
