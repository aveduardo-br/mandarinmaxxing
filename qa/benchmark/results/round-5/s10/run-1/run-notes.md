# Run notes · s10-synonyms · run-1

Scenario: s10-synonyms (HSK 1, Lesson 4 part 3: 明天 会 中文 昨天 汉语). Turns: 50 (T1 to T50). Stopped after the tutor's closing message.

Unclear or uncertain points in SKILL.md / lesson-format.md:

1. Labels missing from the starting course.md. The file lacked Ditado, Áudio and a Rounds line. SKILL.md: "If an older file lacks one, choose it once and save it right away." I chose Ditado, Áudio and Rounds: Chunks, Ações completas, Sequências, and saved them in the final course.md.
2. Synonym follow-up. lesson-format.md: "When the learner keeps choosing one (中文 over 汉语), ask for the other by name in the next prompt that fits and again in the next part's review." It is not said when "keeps choosing" starts (I named 汉语 after the second 中文) or where to store the "again in the next part's review" instruction. I added 汉语 to To reinforce, though that line is defined as items the learner "needed help with".
3. Usage note for 中文 / 汉语. "give each prompt a context that fits only one, such as the contrast ..., or accept both." No situation in HSK 1 vocabulary separates the two, so I accepted both and asked for 汉语 by name.
4. Sense of 会. The map has 会1 in the block "明天 会1 中文" but the skill gives no guidance on whether to teach "will" besides "can". I taught only "can, know how to" and never used 会 as "will".
5. Limited vocabulary. The only place words are 中国 and 哪儿 and there is no 了, 和, 但是 or 的, so past-tense prompts (昨天) and round 3 sequences were hard to make natural. The narration scene (a foreigner in China) is thin. "If the natural sentence needs a word the learner hasn't met, change the prompt" left little room.
6. Frame-sharing rule. "no two prompts share the same frame with only the subject, the time, the place or a name swapped" is hard to apply with about 45 known words (e.g. 1.1 明天她去中国 vs 1.5 昨天他在中国). I varied the verb, but I'm not sure it counts as a different frame.
7. Correction in the last review prompt. "bring that word back in a later prompt of the same or the next round" has no later review prompt for a slip on Review 6, so I returned 今天 in Round 2 and 3 prompts. Likewise the reworked Review 4 kept the total at six, as the skill asks.
8. Older words. "lines 3, 7, 14, 30, and 60 back": only lines 3 and 7 exist (是, 对不起), both used in the review.
9. To reinforce bookkeeping. It was unclear whether dictation sentences count as "used correctly without help during that part" (I counted them) and whether a slip made in the dictation and not retried (我不会) is added (I added it).
10. Audio script display. The `audio-script` block stands for the clip, so the script is visible in the transcript but shown to the student only as the clip. After the narration answers I gave marks only and did not show the script, since lesson-format.md only requires showing it for dictation corrections.
