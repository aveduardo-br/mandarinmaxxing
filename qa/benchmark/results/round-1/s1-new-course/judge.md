## Run 1

**1. Natural Mandarin: 3.** Each Hanzi string is correct word by word, and the pinyin is right, including the tone change in *bú kèqi*. The problem is in the sequences: many expected answers string greetings together in an order no speaker would use, or have one speaker say both sides of an exchange.
- T30 / T44–T53: 你好，你好！ Repeating 你好 to greet one person is odd. Fix: 你好！
- T24 / T48: 谢谢！你好，你好！ / 谢谢！你好！再见！ Thanking someone and then greeting them is the wrong order for an encounter. Fix: 你好！谢谢！再见！
- T82: 对不起！没事！好，谢谢！不客气！ One speaker apologizes, forgives themselves, thanks, and says "you're welcome". Fix: make it an exchange, e.g. 对不起！—— 没事！
- T84: 您好！对不起，没关系！好，谢谢，再见！ The same problem (one speaker says both 对不起 and 没关系). Fix: 您好！对不起！—— 没关系。—— 好，谢谢，再见！
- Dictation 2 (T86): 对不起，没事。 / 谢谢！不客气。 Each line puts both sides of an exchange in one voice. Fix: split each into two dictation sentences said by one person in context, e.g. 对不起！ and 没事，再见！

**2. Whole sentences: 2.** The skill allows "a short line of an exchange ('Hi! Thank you!')" when the learner knows very few words, but many prompts are not lines anyone would say: "Oi, oi! Obrigada! Tchau!" (T30), "Tchau, tchau! Oi! Obrigada!" (T36), "Obrigado! Oi, oi!" (T48). T54's "Olá! (a uma pessoa mais velha, com respeito)" uses a parenthetical scene description to cue 您. Part 2 is slightly better (T66 "Desculpe! Obrigado, tchau!").

**3. Round progression: 2.** Round 1 practices the chunks correctly. In part 1, rounds 2 and 3 are the same task as round 1: shuffled strings of the three words (T18 "Oi! Obrigada, tchau!", T28 "Oi! Obrigado! Tchau, tchau!"). Who, when or where can't be expressed yet, but the rounds don't change shape either, for example to an exchange. In part 2, round 3 gets longer (T82, T84) but only by stacking more interjections.

**4. Only met words: 4.** No prompt needs an unmet word in a strict reading. The tutor uses "senhor" in four prompts (T64, T74, T78, T82) to cue 您, but the table glosses 您 only as "você (forma respeitosa)", so a literal learner could look for 先生, which isn't taught until Lesson 5. The student answered with 您好 each time.

**5. Corrections: 3.** The format is followed every time: the answer in a blockquote, one line with the fix in bold with pinyin, the full sentence once (T14, T20, T62, T68). Pinyin answers are confirmed with the Hanzi (T16, T24, T46), and the keyboard reminder comes once, at the first pinyin answer (T16). Several corrections penalize things that only matter because the prompts are arbitrary:
- T38 marks 你好！谢谢！再见！ wrong for not doubling 谢谢.
- T50 marks the order wrong in a review prompt whose "right" order (thank, then greet) is itself unnatural.
- T32 corrects the order of an equally arbitrary string.

These teach the learner to copy Portuguese punctuation, not Mandarin. T56 handles a valid alternative well (你好 for 您好), names the target chunk, and brings it back in T66.

**6. Listening: 5.** Dictation only, which is right with this few words: no narration is possible. There is one speaker, saved as voice Sarah. The script stays hidden until the learner answers and is then shown with pinyin and meaning. The correction uses the translation format. Dictation 2 uses every new word of the part.

**7. Flow and closing: 5.** The tutor asks one short line for the language (T2), which the skill permits when there is too little text. The setup, overview, bullet format, the one-line list of on-request options, and the route question all follow the skill. Part 1 has no review (correct: nothing has been studied yet). Part 2 opens with a review of five prompts that weaves in the saved items to reinforce. The part 1 closing offers the next part (T42), and the part 2 closing offers the wrap-up (T88). The role-play (T90–T100) has five turns, covers both parts, and gives a meaning under each line. There is no commentary on the plan.

**8. Session length: 4.** Part 1: 15 one-line prompts plus dictation, about 15–20 minutes. Part 2: 5 review prompts, 15 round prompts and a dictation, about 25 minutes. The role-play takes about 5 minutes. The total is about 45–50 minutes, close to the one-hour target. The short part 1 correctly offers part 2.

**Verdict.** A learner gets all nine words, the right formats, clean listening and a well-run role-play. What they don't get is a feel for when each phrase is used: most rounds ask them to reproduce shuffled strings of greetings, and several corrections enforce Portuguese repetition or order rather than Mandarin. The change to the skill that would help most: define what a "whole sentence" is for the very first words. Each prompt is one speaker's line or a short exchange with a marked change of speaker, always in the order of a real encounter.

## Run 2

**1. Natural Mandarin: 2.** The words and pinyin are correct, and the part 2 chunk 谢谢您 is a good, natural choice. The sequences are the least natural of the three runs:
- T28: 再见！谢谢！你好！再见！ (presented as a two-line exchange: "Tchau! Obrigado! / Olá! Tchau!"). Nobody says this. Fix: 你好！谢谢！—— 再见！
- T34: 你好！你好！谢谢！谢谢！再见！再见！ This only doubles every word. Fix: 你好！谢谢！再见！
- T20 / T50: 谢谢！你好！ / 再见！你好！ Thanks or goodbye before hello. Fix: put the greeting first.
- T62: 对不起！没事！谢谢！ This is one line with no speaker change. Fix: 对不起！—— 没事！
- Dictation (T84): 对不起，没关系。 puts both sides of an exchange in one voice. Fix: 对不起！ as one sentence and 没关系，再见！ as another. 不客气，没事。 is plausible as one speaker's reply.
- Role-play (T90–T98): the tea-shop clerk opens by thanking the customer, then says 对不起 and 谢谢 with no event behind them. The Mandarin is correct, but the situation is not.

**2. Whole sentences: 2.** The line breaks in round 3 (T26–T34) make strings look like two-line exchanges, but the lines don't respond to each other ("Tchau! Obrigado! / Olá! Tchau!"). Part 2 prompts like "Obrigado, senhor! De nada! Tchau!" (T64) are coherent only if read as two speakers, and nothing marks that.

**3. Round progression: 2.** The pattern is the same as in run 1. In part 1, round 2 "Ações completas" (T16–T24) contains the same prompts as round 1 ("Tchau! Obrigado!"), and round 3 only adds a line break. In part 2, round 2 starts combining old and new words (T66 "Obrigado, senhor! De nada! Tchau!"), and round 3 is a longer version of the same thing.

**4. Only met words: 5.** No unmet words. The table glosses 您 as "você (respeitoso), senhor(a)" (T52), so "senhor" in the prompts is defined.

**5. Corrections: 3.** The format is right throughout (T12, T54, T60, T66), and pinyin answers are confirmed with the Hanzi (T14, T22, T44). The keyboard reminder comes once, at T14. After T48 the tutor brings the corrected word back, as required. The problems:
- T18 calls 谢谢 "o segundo cumprimento" (the second greeting), which mislabels it.
- T36 marks a sentence wrong for leaving out the sixth word of an artificially doubled string.
- T54 is a good, precise word-order fix (谢谢您, not 您谢谢).

**6. Listening: 5.** Dictation only, one voice, the script hidden until the learner answers, the correction in format, and every new word used in Dictation 1 of part 2 (T84). The only small issue: the listening label ("Escuta") is missing from the clip titles, and both dictations are numbered "Ditado 1".

**7. Flow and closing: 4.** Setup, overview, the on-request line and the route question are all right. Closings: the part 1 closing offers the next part (T40), and the part 2 closing offers the wrap-up (T86). The deductions:
- No `course.md` save is visible anywhere in the transcript, unlike runs 1 and 3, so saving can't be confirmed.
- The role-play has no situational logic.
- The role-play's last line (T100) adds a remark about the course position that wasn't needed.

**8. Session length: 4.** About the same as run 1: part 1 takes about 15–20 minutes, part 2 about 25, and the role-play about 5, for 45–50 minutes in total.

**Verdict.** The mechanics are correct: the right words, the right formats, the right offers. But a learner would practice greetings as abstract strings ("Olá! Olá! Obrigado! / Obrigado! Tchau! Tchau!") and leave without knowing when 谢谢 or 再见 comes in an exchange. The role-play doesn't fix this, because it has no situation either. The change that would help most is the same as for run 1: require each prompt to follow the order of a real encounter, mark the change of speaker, and never repeat a word only to make a prompt longer.

## Run 3

**1. Natural Mandarin: 4.** Most sequences follow a plausible encounter. In part 2, the dash marks the change of speaker ("Obrigado! — De nada! Tchau!", T64; "Olá, senhor! Desculpe! — Não foi nada. Tchau!", T74). The role-play is coherent: an older neighbor, a bump, a held door. The remaining issues:
- T34: 谢谢！你好，谢谢！再见！ Thanks before the greeting. Fix: 你好，谢谢！再见！
- T36: 你好！你好！再见，谢谢！ The doubled greeting. Fix: 你好！再见，谢谢！
- Dictation 2 (T84): 谢谢，不客气！ / 对不起，没关系！ put both sides of an exchange in one voice. Fix: one speaker's lines, e.g. 对不起！ and 没关系，再见！

**2. Whole sentences: 3.** Part 2 prompts are mostly real lines or marked exchanges. Part 1 rounds 2 and 3 are still strings ("Obrigado! Oi, obrigado! Tchau!", T34). T58 uses a parenthetical scene description: "Olá! (de forma educada, a alguém que você respeita)". The role-play's "Sua vez: diga que não tem problema" (T90) tells the learner the content, which is acceptable scaffolding at this stage.

**3. Round progression: 3.** Part 1 is as flat as in the other runs: rounds 2 and 3 repeat round 1 strings. Part 2 is the only real progression in this scenario. Round 1 drills the single chunks. Round 2 has two-speaker exchanges with a reaction (T64, T66, T70). Round 3 has three- or four-line exchanges (T76 "Obrigado! — De nada! Desculpe! — Tudo bem!", T78).

**4. Only met words: 5.** No unmet words. 您 is glossed as "senhor(a)" (T52), which licenses "senhor".

**5. Corrections: 4.** The format is followed every time, each correction points only at the fix, and each reason is useful: T12 "你好 é para dizer oi, na chegada"; T60 / T66 "不客气 responde a um 'obrigado', não a um pedido de desculpas". Pinyin answers are confirmed with the Hanzi (T14, T22, T44). The keyboard reminder comes once, at T14. After T48 the tutor brings the corrected word back in review 5. Small issues:
- T36 penalizes a word left out of an arbitrary string.
- T90 accepts 你好 as a reply to an older neighbor's 您好 without mentioning 您好. This is fine as it stands, but it was a natural teaching moment.

**6. Listening: 5.** The dictation length fits the words available: four sentences in part 1, five in part 2. There is one voice, the script is hidden until the learner answers, the correction is in format, and part 2's dictation uses every new word. There is no narration, which is right.

**7. Flow and closing: 5.** The tutor infers Portuguese, and the setup, overview, on-request line and route question are all right. Part 1 closing: next part plus the offer to continue (T40). Part 2 closing: the wrap-up offer (T86). The role-play has six turns, covers blocks from both parts, gives a meaning under each line, corrects in format, and leaves the position as it was. "Esta parte foi curta" (T40) is only the justification for the offer, not commentary on how the lesson was divided.

**8. Session length: 4.** About 45–50 minutes for both parts and the role-play. Part 1 alone takes about 15 minutes, and the tutor correctly offers part 2.

**Verdict.** This is the most usable run. A learner leaves knowing that 不客气 answers 谢谢 and that 没关系 or 没事 answers 对不起, because the part 2 rounds and the role-play stage real exchanges with marked speakers. The corrections explain why a word fits, not only which word. Part 1 still drills shuffled strings, and the dictation merges two speakers into one voice. The change that would help most is to make run 3's dash convention for exchanges the rule from the first part, with rounds 2 and 3 defined in terms of exchanges while the met words can't say who, when or where.

## Cross-run summary

**Problems in more than one run (these point at the instructions):**
- **Rounds 2 and 3 don't change shape in the earliest part** (all three runs). With three words, "who, when or where" is impossible, so the tutors keep the round titles and repeat round 1 prompts. The skill gives an exception only for round 3 ("early in the jump start that may be a two-line exchange") and none for round 2.
- **Prompts as shuffled strings of interjections, with unnatural order and repetition** (all three runs, worst in run 2). The skill's example "Hi! Thank you!" licenses stringing interjections together, and nothing requires the order of a real encounter or a marked change of speaker.
- **Corrections that enforce the Portuguese prompt's repetition or arbitrary order** (run 1 T32/T38/T50, run 2 T36, run 3 T36). This follows from the previous problem.
- **One speaker saying both sides of an exchange** in prompts (runs 1 and 2) and in dictation (all three: 谢谢，不客气 / 对不起，没关系 / 对不起，没事). The skill's single-speaker rule for listening doesn't say this.
- **Parenthetical stage directions as prompts** to cue 您 (runs 1 and 3: "Olá! (a uma pessoa mais velha, com respeito)").
- **No offer of the next part after part 2**, although the whole sitting stayed under an hour (all three). It's unclear whether "the session ran well under an hour" means the part or the sitting. This is minor, but the wording should settle it.

**Problems seen only once:**
- Run 1: "senhor" cues 您 while the table glosses 您 only as "você (forma respeitosa)", so 先生 (Lesson 5) seems required.
- Run 1: asks the course language first (allowed by the skill).
- Run 2: no visible `course.md` save; a role-play with no situation; 谢谢 called a "cumprimento"; both dictations titled "Ditado 1" and no listening label.
- Run 3: role-play prompts tell the learner exactly what to say (acceptable here, but it lowers the challenge).

**First three changes:**

1. `SKILL.md`, Teach one part at a time: change "When the learner knows very few words, a short line of an exchange (“Hi! Thank you!”) is a whole sentence." to: "When the learner knows very few words, a prompt can be one speaker's line or a short exchange with a dash before each new speaker (“Sorry! — No problem!”). Keep the order of a real encounter: greet, then thank or apologize, then say goodbye. Never repeat a word or shuffle the order just to make a new prompt."

2. `SKILL.md`, Three rounds: after "Round 3 · Sequences. … early in the jump start that may be a two-line exchange.", add: "While the met words can't say who, when or where, round 2 uses two-line exchanges in which the second line reacts to the first (thanks → you're welcome, sorry → no problem), and round 3 uses three- or four-line exchanges of one small scene. Don't repeat round 1's prompts under a new title."

3. `lesson-format.md`, Dictation: change "Three to five short sentences, each a thing someone might say" to "Three to five short sentences, each a thing one person might say in a single turn. Never put both sides of an exchange in one sentence (谢谢，不客气)." Also add this to the prompt rule in `SKILL.md` ("never a fragment or a description of a scene"): "or a stage direction in parentheses; to call for 您, write the line as the learner would say it to that person (“Olá, senhor!”) and gloss 您 as “senhor, senhora” in the table."
