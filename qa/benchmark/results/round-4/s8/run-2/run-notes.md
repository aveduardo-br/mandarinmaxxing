1. Starting course.md had a Labels line without "Ditado" and "Áudio" and no "Rounds" line. SKILL.md: "If an older file lacks one, choose it once and save it right away." 7. The student's pinyin answers contain "de" for 地 and 的 identically, so the tutor cannot tell them apart; I judged it right and named the 地 in the feedback.
8. The audio-script block is shown with the clip, as the runner requires, though lesson-format.md says the script stays out of the message.
