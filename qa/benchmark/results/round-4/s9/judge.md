## Run 1

**1. Natural Mandarin: 4.** Most expected answers are natural, spoken mainland Mandarin, and the round 3 answers in particular read well (T45 我连走回家的力气都没有了). Sentences that sound unnatural:
- T6/T8 (Review 3): 手机突然停止工作了，我现在无法使用它。 The object pronoun 它 and 无法使用 are translationese for a phone. Fix: **手机突然停止工作了，现在没法用了。** (or 现在用不了了).
- T16 (Review 7): 我的新皮鞋走路的时候会发出很大的声音。 This makes 皮鞋 the one that 走路 (the shoes walk). Fix: **我穿新皮鞋走路的时候，鞋会发出很大的声音。** Run 2's version of the same prompt (他走路的时候，他的新皮鞋会发出…) gets this right.

## Cross-run summary

**Problems in both runs (these point at the instructions):**
- Formal review words pull the expected answers toward written or translationese register: 停止工作 / 无法使用它 (run 1), 停止吸烟 (run 2). The pre-send check in SKILL.md names "natural, mainland usage" but nothing about register or whether the subject can do the verb.
- The listening step recycles the rounds. Run 1's narration and dictation 4 echo round 3, and run 2's narration retells T38 and T42 almost line by line. lesson-format.md bans repeating chunks and round 1 prompts in the dictation only.
- Both draw the vocabulary table in Markdown, not the HTML template. This may be the environment, but neither transcript shows that choice being justified.
- Both open a round with the same "every Saturday morning … gym" frame (run 1 T16, run 2 T28). That is a minor sign of a default template.

**Problems seen only once:**
- Run 1: dangling subject 我的新皮鞋走路的时候 (R7). Correction lines without hard line breaks.
- Run 2: round 1 asks for the meaning-line example (在家健身). One chunk repeated verbatim across rounds 2 and 3. The narration's dangling 也办了会员. A weak causal link in dictation 3.

**Three changes I would make first:**
1. SKILL.md, the line "Before sending a prompt, have its Mandarin answer ready and check it as you would a listening script: natural, mainland usage, time words before the verb, only met words." Add: "spoken register (no object 它 where speech drops it, no formal verb such as 停止 or 使用 where speech uses a plain one), and a subject that can really do the verb."
2. SKILL.md, the round 1 line "Never ask for a chunk exactly as listed, or for the example in its meaning line: change at least one slot". Extend it to the whole part: "In any round, never reuse a chunk with the same slots as its listing, its meaning-line example, or an earlier prompt."
3. lesson-format.md, the dictation line "no sentence repeats a chunk or a round 1 prompt as written". Widen it to "no sentence repeats a chunk or any prompt of the part as written", and add to the narration paragraph: "Tell a new scene, not a retelling of a round 3 prompt."
