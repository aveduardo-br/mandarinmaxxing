# Hanzi font

`kaiti-hsk-1-6.woff` is a subset of LXGW WenKai GB Lite (Regular), cut down to the 1,940 characters of HSK levels 1–6 for web font delivery in vocabulary tables. It is not meant to be installed as a desktop font.

- Original font: https://github.com/lxgw/LxgwWenkaiGB-Lite
