# Levels: finishing one

Read this when the learner finishes a level, or when `course.md` says `Next: level complete`.

## When a level ends

A level ends when every lesson on the route has all its parts in the **Done** log: the close of that last part says so and sets `Next: level complete`. In place of the usual closing line, congratulate the learner in one line and offer the next level.

A later chat that finds `Next: level complete` offers the next level again. If the learner declines, leave the file as it is: reviews and extra practice still work.

If they accept:

1. Run `python3 course.py level <course.md> <new level>`. It keeps the whole **Done** log, so words from the finished level keep coming back, and starts the new level's route. Translate the new lesson names in the file, as the command asks, and put the file back.
2. Show the new level's lessons as "Show the level and agree on the route" in `setup.md` describes, without explaining again what lessons and parts are, and ask about the route.
3. Ask whether to start the first part now or next time, and start only if they say now.

The `(known)` marks belong to a level: if the learner ever returns to one, ask again which lessons they know. If they later review a lesson of another level, take its name from `course.py overview` for that level, in the course language.

## After HSK 4

HSK 5 and 6 aren't mapped yet. When the learner finishes HSK 4, congratulate them and say so in one line: reviews, role-plays and extra readings still work with everything they have studied.
